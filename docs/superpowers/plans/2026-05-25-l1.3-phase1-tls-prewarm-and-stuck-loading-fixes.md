### Step 1.1: Create `Stash/TLSPrewarmer.swift`

- [ ] Write the new file with this exact content:

```swift
import Foundation
import os

/// Fire-and-forget pre-warm of the TLS session against the Whisper base URL.
///
/// The first record-and-upload in a freshly launched app pays the cost of
/// DNS resolution + TCP handshake + TLS handshake before the multipart
/// upload begins (typically 100–300ms on cold connections). Issuing a
/// throwaway GET during `applicationDidFinishLaunching` populates
/// `URLSession.shared`'s connection pool so the same host can be reused by
/// the real upload, eliminating that overhead from the user-perceived
/// latency budget.
///
/// Everything here is best-effort. The endpoint we hit (Whisper base URL
/// without the `/audio/transcriptions` suffix) will typically return 404 or
/// 405 — that's fine. We only care about establishing the connection.
/// Errors are swallowed; the real upload path has its own error handling.
enum TLSPrewarmer {

    private static let logger = Logger(
        subsystem: "com.stash.transcription",
        category: "tls-prewarm"
    )

    /// Issue a discarded GET against the transcription base URL. Safe to
    /// call from any actor context — work runs on a detached Task at
    /// utility priority so it never competes with UI or user-initiated
    /// network. Idempotent; calling twice just opens two connections (the
    /// second will be reused from the pool the first established).
    static func warm() {
        guard let url = URL(string: APIConstants.transcriptionBaseURL) else {
            logger.warning("transcriptionBaseURL is not a valid URL — skipping pre-warm")
            return
        }
        Task.detached(priority: .utility) {
            var request = URLRequest(url: url)
            request.httpMethod = "GET"
            request.timeoutInterval = 3
            let started = Date()
            do {
                _ = try await URLSession.shared.data(for: request)
                let elapsed = Int(Date().timeIntervalSince(started) * 1000)
                logger.info("Warmed in \(elapsed, privacy: .public)ms")
            } catch {
                let elapsed = Int(Date().timeIntervalSince(started) * 1000)
                logger.info("Warm attempt finished in \(elapsed, privacy: .public)ms (error swallowed: \(error.localizedDescription, privacy: .public))")
            }
        }
    }
}
```

## Task 4 — Wire `processingWatchdog` as 90s safety net

**Goal:** `processingWatchdog: DispatchWorkItem?` has been declared in `TranscriptionService` for ages but is never scheduled. If the queue + notification observer + cleanup-failure paths all somehow leak (e.g., a future code path forgets to call `clearProcessingHonoringFloor`), `isProcessing` is stuck forever. Wire a 90-second safety net from `stopRecording` that always fires unless cancelled by a normal terminal path.

**Files:**
- Modify: `Stash/TranscriptionService.swift` (in `stopRecording`, `uploadSession`, `clearProcessingHonoringFloor` and the new failure-overview paths from Task 3)

### Step 4.1: Add a helper to schedule + cancel the watchdog

- [ ] Add two private helpers near the bottom of the `TranscriptionService` class (just above the `#if DEBUG` test-seam section at the end). They centralize the scheduling so every call-site is one line.

```swift
    /// 90s safety net: if no terminal path clears the processing pill in
    /// time, force-clear it via `clearProcessingHonoringFloor`. Cancellable
    /// via `cancelProcessingWatchdog()`. Idempotent: rescheduling cancels
    /// the prior work item before scheduling the new one.
    private func scheduleProcessingWatchdog() {
        processingWatchdog?.cancel()
        let item = DispatchWorkItem { [weak self] in
            guard let self else { return }
            Task { @MainActor [weak self] in
                guard let self else { return }
                #if DEBUG
                print("[Transcription] processingWatchdog fired — force-clearing isProcessing after 90s")
                #endif
                await self.clearProcessingHonoringFloor()
                self.processingWatchdog = nil
            }
        }
        processingWatchdog = item
        DispatchQueue.main.asyncAfter(deadline: .now() + 90, execute: item)
    }

    /// Cancel any pending watchdog and clear the slot. Safe to call when
    /// no watchdog is scheduled.
    private func cancelProcessingWatchdog() {
        processingWatchdog?.cancel()
        processingWatchdog = nil
    }
```
